# 카드 이야기 AI 1차 검토 — 클라우드 세션 몫 (2026-10-28)

한칸이야기는 아이가 카드 네 장(장소 · 문제 · 행동 · 결과)을 고르면 미리 만들어 둔 이야기를 꺼내 준다.
조합 512개 × 네 판(긴 판 · 나레이션 / 긴 판 · 캐릭터 목소리 / 짧은 판 · 나레이션 / 짧은 판 · 캐릭터 목소리)을 만들었고,
사람이 다 읽기 전에 AI 가 「사람이 꼭 읽어야 할 문제」를 짚는다. 422조합은 API 배치가, **남은 90조합(`bundle.jsonl`)은 이 세션이** 한다.

- `RUBRIC.md` — 판정 기준과 답 형식 (API 배치와 똑같은 지시문)
- `bundle.jsonl` — 한 줄에 조합 하나: `combo`(키) · `cards` · `fingerprint` · `text`(네 판 글)
- 이름 자리 `{이름}{조사:가}` 는 캐릭터 판에서 아이가 지은 이름이 들어갈 자리다 (조사는 받침에 맞춰 바뀐다)
- 이야기는 AI(Claude)가 쓴 글이고 아이 자료가 아니다

결과: `review_ai_cloud.jsonl` — 한 줄에 조합 하나
`{"combo": "...", "fingerprint": "(bundle 의 값 그대로)", "verdict": "pass|check", "issues": [{"version", "type", "quote", "why"}]}`
