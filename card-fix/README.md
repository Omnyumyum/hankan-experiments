# 카드 이야기 고쳐 쓰기 — AI 검토가 짚은 것만 (2026-10-29)

사람이 2,048편을 다 읽을 수 없어서, AI 검토가 짚은 편만 고쳐 쓴다.

- `requests/<id>.json` = `{"id", "system", "user"}` — system 은 처음 이야기를 쓸 때와 같은 지시문 + 맨 아래 「고쳐 쓰기 — 이번에 할 일」.
  user 에 「지금 대본 / 지금 글」과 「고칠 점」이 있다.
- id 머리말: fixbase = 기본판(긴 판 · 나레이션) 고치기 · fixlc = 긴 판 · 캐릭터 · fixsn = 짧은 판 · 나레이션 · fixsc = 짧은 판 · 캐릭터.
- 답: 고친 이야기 **전체**만 `responses/<id>.txt` 에. 지시문이 JSON 이면 JSON 하나(설명 · ``` 없이), fixsn 은 네 문장 글만.
- **고칠 점만 고치고 나머지는 그대로.** 캐릭터 판의 「한 문장 안에 나레이션 + 대사」 형식은 일부러 만든 것이라 바꾸지 않는다.
- 답은 백엔드가 처음과 똑같이 검사한다. 이야기는 아이 자료가 아니다.
