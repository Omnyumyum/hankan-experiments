# ChildlikeSHAPES 와 다른 아이 그림 데이터 살펴보기 (2026-10-27)

**한 줄 요약:** ChildlikeSHAPES 는 받았지만 **README 의 암호로 안 풀려서 속을 못 봤다.** 대신 지난번 막혔던
Meta **Amateur Drawings(MIT)** 를 이번엔 받을 수 있어서, **종이에 그려 휴대폰으로 찍은 실제 아이 그림**으로 처음 쟀다.
가장 큰 문제는 종류 추측도 움직임도 아니고 **마스크**였다: 무작위 사진 600장 중 **정답 마스크와 IoU 0.5 미만이 41%**(확인용 287장 중 122장, 43%).
코드는 고치지 않았다(재기만).

## 1. ChildlikeSHAPES — 받았지만 열리지 않음
| 항목 | 내용 |

| 출처 | github.com/facebookresearch/AnimatedDrawings, 릴리스 `v0.0.1` 의 `datachunk_aa` · `ab` · `ac` (2025-02-19 올림) |
| 라이선스 | README: CC BY 4.0 (상업 이용 가능, 출처 표시) |

확인한 것:
- 릴리스 자산 목록에 `datachunk_*` 는 이 셋뿐이다(나머지 137개는 `ad_orig_img_fs_*`). `cat datachunk_* > full_archive.7z` 로 합친 파일의 7z 머리 정보가
  가리키는 끝 위치가 파일 크기와 **바이트까지 맞는다** → 조각이 빠지거나 깨진 것은 아니다.
- 7z 머리(파일 목록)까지 암호로 잠겨 있어 **그림 수 · 종류 · 정답 표시 · 사진/스캔 여부를 하나도 알 수 없다.**
- 암호 철자를 바꿔 본 것(1↔l, 0↔O, 대소문자, 괄호 포함 등 18가지)도 모두 틀림. README 의 암호 줄은 처음 들어간 커밋(9ac3f31) 뒤로 바뀐 적이 없다.
  저장소는 2025-09-03 에 보관(archived)되어 이슈를 새로 열 수 없다. 이슈 검색에도 ChildlikeSHAPES 이야기는 없었다.
- 그래서 할 일 1의 질문(그림 수 · 종류 · 정답 표시 · 사진/스캔)에는 **답하지 못했다.** 받은 파일은 지웠다.

## 3. Amateur Drawings 로 잰 것

### 무엇을 골랐나
- 받은 것: HF 사본 parquet 0~7번 = **14,224장**(모두 사진. 종이 · 책상 · 그림자 · 줄 공책 · 모눈 종이가 함께 찍힘, 색칠한 그림이 많음).
- **이 데이터는 「사람 꼴」 그림만 모은 것이다.** Meta 데모에서 사람 꼴 검출 + 사용자가 확인한 그림만 들어 있다.
  설명 글에 동물 이름이 있는 그림 651장(cat 932 · bird 391 … 중 무작위)을 눈으로 봤더니 **서 있는 사람 꼴 동물이 대부분**이고 진짜 비휴머노이드는 20장(3%)뿐이었다.
  그래서 정답 마스크가 가로로 긴(가로/세로 > 1.2) 658장을 더 봤다. **모두 1,309장을 눈으로 보고** 라벨을 붙였다:

| 라벨 | 뜻 | 기대 종류 | 장수 (학습 / 확인) |
|---|---|---|---|
| Q | 네 발 동물(옆 · 앞 모습, 앉은 고양이 포함) | 네 발 | 22 (14 / 8) |
| W | 날개가 보이는 것(새 · 나비 · 박쥐 · 날개 달린 하트) | 날개 | 33 (12 / 21) |
| L | 긴 몸(누운 유령 등) | 긴 몸 | 2 (1 / 1) |
| B | 팔다리 없는 덩어리(별 · 로켓 · 호박 · 둥근 몬스터) | 몸통만 | 11 (5 / 6) |
| F | 얼굴만 그린 것 | 몸통만 | 33 (12 / 21) |

  비휴머노이드(Q·W·L·B)는 **68장뿐**이다. 숫자 하나하나가 몇 장 차이로 바뀐다(아래 숫자는 「경향」으로 읽을 것). 라벨은 한 사람 눈으로 한 번 매겼다.
- 마스크는 그림 종류와 상관없으므로 **전체에서 무작위 600장**(seed 7, 거의 다 사람 꼴)으로 따로 쟀다.
- 몫: id **마지막** 글자 0-7 = 학습용(원인 보기), 8-f = 확인용(판단). (받은 parquet 이 id 순 정렬이라 첫 글자는 거의 0 · 1 이었다 — 처음에 첫 글자로 나눴다가 한쪽으로 쏠려서 고침.)
- 그림은 `sr.load_image` → `Drawing` → `propose` → 기대 종류로 `animate`(미리 놓은 점 그대로). 기준은 `run_eval.py` 와 같다(늘어남 > 5배, 뒤집힘 > 1%).
  마스크 IoU 는 우리 `alpha` 를 **원래 사진 좌표로 되돌려** 정답과 맞댔다(자르기 상자 계산이 실제와 같은지 686/686장 픽셀까지 확인).

### 마스크 — 무작위 600장 (가장 큰 문제)
| | 학습용 313 | **확인용 287** | 합계 600 |
|---|---|---|---|
| `Drawing` 실패 (「그림 선을 찾지 못했다」) | 4 (1.3%) | **8 (2.8%)** | 12 (2.0%) |
| IoU < 0.5 | 126 (40%) | **122 (43%)** | 248 (41%) |
| IoU < 0.7 | 182 | 166 | 348 (58%) |
| IoU 중앙값 | 0.594 | **0.582** | 0.587 |
| 한 장 시간 평균 / 최대 | | | 0.50 / 3.7초 |

IoU < 0.5 의 원인 (자동 분류: 자르기 상자가 정답의 90%를 못 담음 → A, 우리 마스크가 정답의 1.5배 넘음 → B, 0.6배 안 됨 → C, 나머지 D):

| 원인 | 학습용 | **확인용** | 눈으로 본 모습 (`childlike/sheet_mask_train.png`, 학습용 24장) |
|---|---|---|---|
| B 너무 넓음 | 69 | **68** | 종이 한 장 통째 · 책상 · 그림자 · 줄 공책/모눈 선 · 손가락 · 옆에 그린 해/구름/집까지 몸으로 잡음 (24장 중 14장) |
| A 자르기가 그림을 놓침 | 31 | **26** | 연필 선이 연해서 일부만 잡히거나 파란 종이 · 그림자 쪽을 그림으로 잡음 (6장) |
| C 너무 좁음 | 13 | **20** | 연한 선이 안 닫혀 안이 안 채워짐 (2~3장) |
| D 모양이 다름 | 13 | 8 | 한 종이에 사람이 둘 — 다른 쪽을 잡음 등 (1장) |
| 실패 | 4 | 8 | 너무 연함 |

- 「색칠한 곳을 몸에 더함」이 켜진 그림은 B(너무 넓음)에서 51/137, 잘 된 것에서 31/340 — **색 더하기가 종이 · 배경색까지 끌어들이는 경우가 많다**(학습용에서 본 것: 노란 책상, 파란 종이, 빨간 마커 칠 주변).
- QuickDraw(흰 바탕 선만)에서는 마스크 실패 0 이었다. **사진에서는 종이 · 배경 분리가 안 된다**는 것이 이번에 처음 보인 빈칸이다.

### 비휴머노이드 68장 + 얼굴만 33장 — 종류 추측과 움직임
| 라벨 (확인용 장수) | 마스크 IoU<0.5 | 추측 맞음 / 틀림 / 모르겠음 | 망가짐 (늘어남>5 · 뒤집힘>1%) | **쓸 만함** (IoU≥0.5 · 안 망가짐) |
|---|---|---|---|---|
| Q 네 발 (8) | 4 | 5 / 2 / 1 | 0 | **4 / 8** |
| W 날개 (21) | 10 | 0 / 5 / 16 | 2 (늘어남 1 · 뒤집힘 2) | **11 / 21** |
| L 긴 몸 (1) | 0 | 0 / 0 / 1 | 0 | 1 / 1 |
| B 몸통만 (6) | 2 | 1 / 1 / 4 | 0 | 4 / 6 |
| **Q·W·L·B 합 (36)** | **16 (44%)** | **6 / 8 / 22** | **2 (6%)** | **20 / 36 (56%)** |
| F 얼굴만 (21) | 15 (실패 1) | 1 / 5 / 14 | 0 | 5 / 21 |

학습용(Q 14 · W 12 · L 1 · B 5 = 32장)도 같은 모양이다: IoU<0.5 16, 추측 5 / 3 / 24, 망가짐 1, 쓸 만함 16/32. 얼굴만 12장: 추측 틀림 5(모두 네 발).

- **망가짐(늘어남 · 뒤집힘)은 적다**: 68장 중 3장. 날개 방식은 칸 맞춤 27 · 점 3개 6.
  하지만 이 숫자는 **마스크가 틀려도 「안 망가짐」으로 셈한다** — `childlike/sheet_motion_check.png` 에서 종이 아래 책상 조각을 달고 걷는 고양이(Q 029557),
  배경의 빨간 칠을 날개로 잡아 펄럭이는 W 00115c, 줄 공책 한 장이 통째로 출렁이는 F 를 봤다. 그래서 「쓸 만함」은 마스크까지 본 숫자로 따로 적었다.
- 마스크가 맞은 그림은 움직임이 괜찮다: 날아가는 새(W 0fd184)와 날개 달린 하트(W 02da29)는 날개만 깔끔히 친다. 누운 유령(L)도 자연스럽다. 앉은 고양이(Q 0e3efb)는 다리가 조금 움직인다.
- **추측:** 날개 33장 중 맞음 1장. 사진 속 날개(정면 새 · 박쥐 · 날개 달린 하트)는 QuickDraw 낙서와 달리 「모르겠음」이 대부분이고 틀릴 땐 네 발로 간다.
- **사람 꼴 그림에 대한 추측**(무작위 600장, 거의 사람): 확인용 279장 중 **70장(25%)이 넷 중 하나로 추측됨**, 대부분 네 발(51). 막대 사람의 두 다리 + 두 팔을 네 다리로 본다.
  지금은 카드에 힌트로만 보여 주니 큰 문제는 아니지만, 「자신 있으면 카드 없이 바로」는 사진에서는 위험하다.
- 얼굴만(F) 33장 중 네 발로 추측 10장. `looks_face_only` 는 사진 마스크가 종이까지 커지면 걸리지 않는다(학습용에서 본 것).

## 4. 다음에 고칠 것 (순위, 이번엔 고치지 않음)
1. **사진에서 종이 · 배경 떼기 (`shape_rig.crop_and_mask`)** — 확인용 무작위 287장 중 IoU<0.5 가 43%, 그중 절반 이상이 「너무 넓음」.
   종이 영역을 먼저 찾고(밝고 큰 사각형) 그 안만 보기, 줄 공책 · 모눈 선 빼기, 「색칠 더하기」를 종이색과 비교할 때 종이 안쪽만 쓰기.
   학습용 313장으로 고치고 확인용 287장 + 비휴머노이드 확인용 36장으로 판단하면 된다(재는 도구는 이미 있음: `childlike/ad_eval.py`).
2. **연한 연필 선 놓침 (자르기 상자 A · 실패 · C)** — 확인용 54장(19%). 사진은 대비가 낮다. 문턱값을 사진 밝기에 맞추기.
3. **한 종이에 여러 그림** — 가장 큰 덩어리만 잡는데 옆의 해 · 구름 · 다른 사람이 붙어 들어온다. 사람에게 「어느 그림?」 탭을 받는 것이 더 확실할 수 있다.
4. **사진 속 날개 추측** — 날개 33장 중 맞음 1. 다만 표본이 작다. 1~2 를 고친 뒤 다시 재야 의미가 있다(지금은 마스크가 틀려 추측 특징도 틀린다).
5. **더 많은 비휴머노이드 사진** — Amateur Drawings 에서 68장을 모으려고 1,309장을 봤다. ChildlikeSHAPES 가 열리면(암호 확인) 그쪽이 먼저다. 아니면 HF 사본을 더 받아 같은 방식(가로로 긴 마스크 + 눈)으로 늘린다.

가장 회의적인 것: 4번(추측 손보기). 마스크가 틀린 상태에서 추측 기준을 바꾸면 틀린 마스크에 맞춰 고치게 된다.

## 다시 재기
- 받기: `curl -L https://huggingface.co/datasets/keshan/amateur_drawings-controlnet-dataset/resolve/main/data/train-0000{0..7}-of-00100-*.parquet` (파일 이름은 API `/api/datasets/keshan/amateur_drawings-controlnet-dataset/tree/main/data` 로).
- 꺼내기: pyarrow 가 있는 파이썬으로 `python -I eval_real/childlike/ad_prep.py --pq parquet폴더 --labels eval_real/childlike/ad_labels.csv --n 600 --out 꺼낼폴더` (14,224장 중 699장)
- 재기: `../venv/bin/python -I eval_real/childlike/ad_eval.py --data 꺼낼폴더 --out 결과.csv` → `childlike/ad_results.csv` 와 같은 결과
- 모아 보기: `ad_mask_sheet.py --split train` · `ad_motion_sheet.py --split check`
- 받은 parquet · 꺼낸 PNG 는 올리지 않았다. 올린 그림(`sheet_*.png`)은 Amateur Drawings(MIT) 사진으로만 만들었다.

## 아직 안 되는 것
1. **ChildlikeSHAPES 속을 못 봤다** (암호). Meta 쪽에 맞는 암호를 물어볼 길이 필요하다(저장소는 보관 상태).
2. 비휴머노이드가 68장이라 종류별 숫자가 작다(네 발 확인용 8장, 긴 몸 2장). 라벨은 한 사람이 한 번 매긴 것이다.
3. 「부위」 정답은 없다 — Amateur Drawings 의 관절은 사람 관절이라 네 발 · 날개 점과 맞댈 수 없었다. 마스크만 맞댔다.
4. 정답 마스크 자체가 HF 사본을 거친 것이다(512px 로 줄어든 것으로 보임). 원본 주석(275MB JSON)과 맞대 보지는 않았다.
