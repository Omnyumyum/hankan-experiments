# 실제 사진에서 그림 잘라 내기(마스크) 고치기 (2026-10-27 ~ 28)

**한 줄 요약:** 사진을 먼저 「스캔한 그림처럼」 정리하는 함수 `rig_types.clean_photo` 를 더했다.
실제 아이 그림 사진(Meta) **확인용 2859장에서 마스크 실패 45.1% → 28.8%**, 3배로 키운 사진 38.5% → 27.5%.
QuickDraw 사진 변환에서는 줄 공책 · 지우개 자국 · 나쁜 사진이 크게 좋아졌지만 **그림자(+10) · 보통 사진(+6) · 고르지 않은 조명(+3)은 조금 나빠졌다**(아래).
기존 검사는 모두 그대로다(guess_eval 3000장 추측은 한 장도 안 바뀜).

## 무엇을 바꿨나 (`rig_types.py`: `clean_photo` + 도우미 `_find_paper` · `_rule_lines` · `_fill_holes` · `_disk`, `Drawing.__init__` 한 줄)

`Drawing` 이 `paper_only`(종이 밖 지우기, 그대로 둠) 다음에 `clean_photo` 를 부른다. 판단은 긴 변 512px 로 줄인 그림에서 하고, 결과는 원래 크기 · 좌표 그대로 만든다(그래서 `shape_rig.crop_and_mask` 는 손대지 않았다).

1. **선 찾기:** 바탕 밝기보다 어두운 곳 + 둘레와 색이 다른 곳. 바탕은 중앙값으로 잡아서 그림자 경계 · 지우개 자국처럼 넓고 연한 얼룩은 바탕이 된다.
2. **종이 찾기:** 128px 그림에서 가운데 밝은 곳 여러 점부터 색이 천천히 바뀌는 데까지 채운다. 밝기 차이는 1/3 로 줄여 봐서 그림자를 넘어간다. 바깥보다 밝거나 바깥이 더 얼룩덜룩하고, 네모에 가까울 때만 믿는다(아니면 사진 전체를 종이로 봄). 종이 밖 선은 버린다.
3. **넓게 칠한 곳 더하기:** 큰 크레파스 칠은 1번에서 가운데가 빠져 그림이 조각났다(고른 조각 밖은 다 지워져 그림이 사라짐). 종이 색과 색이 다르거나 아주 어두운 곳을 더한다. 사진 테두리에 닿는 덩어리(책상 · 그림자 · 배경)는 뺀다.
4. **공책 줄 · 모눈 지우기:** 허프 선 중 같은 방향 선이 서로 다른 자리에 4개 넘게 있거나(굵은 선 하나가 허프 선 여럿으로 나오는 것은 하나로 셈), 고른 간격으로 긴 가는 선이 5개 넘게 있으면 공책 줄. 사진 반쯤 되는 긴 선 하나는 그림 선보다 연할 때만 지운다(말 목 · 별 변은 남김). 줄보다 훨씬 진한 곳은 줄 위를 지나는 그림 선이라 남긴다. 칠한 곳은 자르지 않는다.
5. **깨끗한 그림은 그대로 돌려줌:** 종이가 사진을 채우고, 맨 종이가 완전히 고르거나(그린 파일) 고르고 선이 진하고, 공책 줄이 없으면 아무것도 안 바꾼다. 그림만큼 진한 「줄」(빗금 · 털)은 공책으로 치지 않는다.
6. **그림 하나 고르기:** 가까운 선끼리 묶어서 가장 큰 묶음(가운데일수록, 사진 테두리에 안 닿을수록 더 쳐줌) + 그 둘레 안의 묶음만 남긴다. 떨어진 다른 그림 · 글자 · 책상 물건이 빠진다.
7. **다시 그리기:** 고른 그림 밖은 종이 색(종이만 넓게 흐린 색, 먼 곳은 중앙값으로 부드럽게)으로 칠한다. 연한 선은 종이보다 적어도 80 어둡게, 1~2px 가는 선은 한 겹 굵게(shape_rig 의 3×3 열기에서 사라지므로). 지우개 자국처럼 그림 선보다 훨씬 연한 것은 진하게 하지 않는다.

평가 스크립트: `eval_real/photo_mask_eval.py`(새로, Meta 마스크만 잼), `colored_eval.py` · `colored_sheet.py` 는 `clean_photo` 가 있으면 그것을 거친 그림에서 자른 곳을 계산하게만 바꿨다.

  - 나쁜 사진 칸: dog · horse · cloud 는 좋아짐(0.40 → 0.49, 0.55 → 0.78, 0.29 → 0.42), **snake 는 나빠짐(0.37 → 0.23, 그림자 덩어리가 붙음)**, butterfly 0.89 → 0.82.
  - 글자 칸: 그대로(그림에 닿은 글자는 같은 묶음이 된다).
- 저장소 밖(Meta 라이선스): 학습용 실패 모아 보기 수십 장, 확인용 실패 전후 100장씩(위 원인 표), 고치는 중 나빠진 그림들의 내부 단계 그림(종이 · 선 · 묶음 · 결과).

## 아직 안 되는 것
1. **실제 사진 마스크 실패가 여전히 29%.** 가장 큰 것은 ① 여러 그림 · 글자 · 땅 선이 붙거나 다른 그림을 고름(약 200장), ② 아주 연한 연필 · 점선 · 작은 그림(약 165장), ③ 줄 · 모눈 공책(약 130장, 줄이 끊기거나 휘거나 그림만큼 진한 경우).
2. **그림 하나 고르기의 부작용:** 몸에서 멀리 떨어진 조각(머리 · 눈)을 다른 그림으로 보고 지운다(QuickDraw 그림자 2장). 반대로 인물이 여럿인 사진에서 정답과 다른 인물을 고르면 실패다 — 사람에게 고르게 하는 게 맞다.
3. **새로 생긴 실패:** 종이 결 · 크레파스 결이 점처럼 잡힘(~49장), 엉뚱한 묶음을 골라 그림이 사라짐(~33장).
4. QuickDraw 그림자 · 조명 · 보통 사진 변환은 마스크 실패가 3~10장 늘었다(대부분 열린 윤곽을 채운 차이, 2장은 진짜).
5. 큰 사진(3000px)에서 한 장 1.3초 더 든다. 나쁜 사진의 추측 맞음이 줄었다(46 → 37).
6. Meta 정답 윤곽이 이상한 그림(종이 전체 · 줄까지 정답)이 확인용 실패의 7% 쯤이다 — 이것은 고칠 수 없다.
7. Meta 그림은 512px 로 줄어 있어 실제 휴대폰 사진 결과는 여전히 모른다(×3 은 흉내). 원근 펴기(사다리꼴 종이를 네모로)는 하지 않았다 — 좌표가 바뀌어 뒤 단계(점 · 움직임)를 다 고쳐야 해서.
8. Meta 데이터 라이선스(MIT ↔ CC BY-NC) 확인 전에는 학습 · 서비스에 쓰지 말 것.
