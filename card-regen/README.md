# 「어두워졌어요」 카드 이야기 다시 쓰기 — 클라우드 세션 몫 (2026-10-28)

한칸이야기는 아이가 카드 네 장을 고르면 미리 만든 그림책 대본을 꺼내 준다. 「어두워졌어요」 128조합에서
아이가 어른 없이 밤에 혼자 남는 이야기가 나와(AI 검토 46조합), 지시문에 규칙을 넣고 다시 쓴다.

- `requests/<id>.json` = `{"id", "system", "user"}` — 서비스가 Claude API 에 보내는 지시문 · 메시지와 글자 하나 다르지 않다.
- 할 일: 파일마다 **system 을 자기 지시문으로 삼아** user 메시지에 답한다. 답 글만 `responses/<id>.txt` 에 쓴다
  (지시문이 「JSON 으로만 답한다」고 하면 JSON 하나만 — 앞뒤 설명 · ``` 없이).
- 답은 백엔드가 API 결과와 똑같이 검사한다 (카드 글자 · 쪽 배치 · 첫 쪽 자리 · 배경 지시문 · 내용 검사). 걸린 것만 다시 나온다.
- 이야기는 아이 자료가 아니다. 아이가 고른 것은 카드 글자뿐이다.
